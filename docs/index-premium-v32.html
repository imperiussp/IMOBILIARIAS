BLOQUEIO REAL

Supabase exclusivo ainda não existe.

A conta conectada possui apenas o projeto MOTO-CONNECT. Ele não será reutilizado nem alterado. Para avançar para banco, Auth, Storage e Edge Functions reais, o IMOBILIÁRIAS precisa de um projeto Supabase próprio.

Enquanto isso, todo o código e a prévia continuam sendo fechados sem tocar em infraestrutura de outro projeto.
