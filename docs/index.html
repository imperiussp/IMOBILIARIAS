DÚVIDAS FREQUENTES

Como vai funcionar?

Cada imobiliária terá um site separado?

Visualmente, sim. Tecnicamente, todos usam a mesma plataforma, mas cada imobiliária enxerga e publica somente seus próprios dados.

Posso usar meu próprio domínio?

Sim. Nos planos que tiverem esse recurso, o domínio da imobiliária poderá apontar para a nossa infraestrutura e abrir somente o ambiente daquela empresa.

O endereço padrão continuará funcionando?

Sim. A imobiliária poderá manter um endereço como nome.imoveis.lenoy.com.br mesmo depois de conectar um domínio próprio.

A imobiliária terá painel próprio?

Sim. Cada empresa terá acesso ao painel para administrar imóveis, corretores, contatos, configurações e demais recursos permitidos pelo plano.
